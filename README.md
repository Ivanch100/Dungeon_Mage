# Огненный маг — APK для Android (без Play Маркета)

Сборка в облаке GitHub, ничего устанавливать на компьютер не нужно.
1. Создай бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузи в него содержимое этой папки (вместе с папкой .github).
3. Вкладка Actions -> Build APK -> Run workflow. Подожди 5-10 минут.
4. Открой завершённую сборку -> раздел Artifacts -> скачай fireball-mage-apk (внутри app-debug.apk).
5. Перенеси APK на телефон, открой его и разреши установку из неизвестных источников.

Если сборка упала, открой лог шага и пришли мне ошибку: версии Capacitor и Java меняются.
Быстрый вариант без сборки: открой ссылку с игрой в Chrome на Android -> меню -> «Установить приложение».
